# Smart Voice-to-Text Productivity Assistant

A minimal desktop-based productivity application that converts real-time voice input into accurate text.  
The project focuses on applying software design patterns and building a practical, installable product.

---

## Objective
To develop a lightweight voice-to-text desktop application that improves productivity for students and professionals by enabling fast and accurate speech transcription.

---

## Tech Stack
- **Frontend:** React.js, HTML, CSS, JavaScript  
- **Desktop Framework:** Tauri  
- **Speech Recognition:** Deepgram API  
- **Database:** SQLite  
- **Version Control:** Git & GitHub  

---

## Design Pattern
- **MVC (Model–View–Controller)**  
  - Model: Transcription data handling  
  - View: User Interface  
  - Controller: Audio input & API interaction
